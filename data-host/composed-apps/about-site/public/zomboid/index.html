Flight Group Alpha: Project Zomboid

Build 42 stable, multiplayer. This page lists what you need installed before you join.

Before you join

  1. Use the normal Steam version of the game. Build 42 is the default branch now. In Steam, open the game's Properties, then Betas, and choose None.
  2. Subscribe to the collection. Open the server collection and press Subscribe to All.
  3. Subscribe to the extra mods. These are on the server but may not be in the collection yet:
    • True Music B42. Boomboxes, car cassette decks and vinyl players.
    • True Music B42.20 - Multiplayer Fixes. Fixes for True Music in multiplayer. Everyone needs it.
    • True Music: Mixtape Megapack. Over 100 mixtapes, more than 800 songs, all from before July 1993.
    • True Music Radio: WRPZ 93. A Louisville rock station with a DJ, recorded as 20 half-hour tapes.
    • True Music Radio 42. Radio stations that play the music packs for everyone.
    • Carry Weight Multiplier. Raises everyone's carry capacity. The server sets it to 1.4 times vanilla.
  4. Turn the body mod on in the main menu. Body mods only load when the game starts. In the main menu open Mods, enable Tomb's Player Body, Tomb's Player Body - Textures [NUDE] and the Compatibility mod, then restart the game once.
  5. Join. Server zomboid.rt-541.io, port 16261. Ask in Discord for the password. The game enables the rest of the server's mods for you when you connect.

Radio

  • Tune any radio to 92.0, 92.2, 92.4, 92.6 or 92.8 FM. TV channel 211 plays music too.
  • Stations play the music packs above. Everything is from July 1993 or earlier.
  • A radio you just tuned can be out of step with other radios until the next song starts.
  • Handheld radios are only heard by the person carrying them.
  • Tapes and records also turn up as loot and play in boomboxes and cars.

Good to know

  • The world is new. Everyone starts a fresh character.
  • If the game says a mod file does not match, unsubscribe from that mod, subscribe again, and restart Steam.
  • Some collection items offer several versions. The server picks one, listed below. You do not need to choose.

Collection items the server does not run

  • Easy Config Chucked: no Build 42 files in the workshop item.
  • an item that was removed from the Workshop: not available on the Steam Workshop.
