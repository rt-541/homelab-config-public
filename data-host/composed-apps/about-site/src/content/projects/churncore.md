A framework mod (engine, stages, registries, UI, client/server state sync), an events mod driving missions, radio broadcasts, and music, and a bridge to the Bandits NPC mod. The world escalates through stages under an event director: supply drops, horde spawns, weather events, all steerable from an in-game admin panel and dashboard.

Built in Lua against Build 42 multiplayer, with unit tests and a scripted deploy loop. In active development.
