# How to join DeceasedCraft

**Server address:** `minecraft.rt-541.io:25567`
**Pack:** DeceasedCraft (Urban Zombie Apocalypse) **5.10.16** · Minecraft **1.20.1** · Forge 47.4.0

> This is the same address as ATM9. Only one world runs at a time — use `/swap`
> in Discord to switch which one. Your connect address never changes.

---

## 1. Get Minecraft: Java Edition

You need **Minecraft: Java Edition** (the PC version, with a Microsoft account).
The Bedrock/console/phone version will **not** work. Buy it at
<https://www.minecraft.net/store/minecraft-java-bedrock-edition-pc> if you don't
have it.

## 2. Install the CurseForge app

The CurseForge app installs the whole modpack for you (Forge + every mod) — you
do **not** install mods by hand.

1. Download it: <https://www.curseforge.com/download/app>
2. Install and open it, choose **Minecraft** as the game.

(Prism Launcher or the FTB app also work if you prefer them, but CurseForge is
the simplest.)

## 3. Install the DeceasedCraft modpack

1. In CurseForge, click **Browse / Search** and search for **DeceasedCraft**
   (full name: *DeceasedCraft - Urban Zombie Apocalypse*).
2. Click **Install**. To match the server exactly, open the version dropdown and
   pick **5.10.16** (newer is fine only if the server has also been updated).
3. Wait for it to download — it's a few GB, so give it time.

## 4. Give it enough memory

DeceasedCraft is heavy. In CurseForge: **Settings → Minecraft → Allocated
Memory**, set it to about **8 GB** (8192 MB). Less than 6 GB will lag or crash.

## 5. Launch and connect

1. Hit **Play** on the DeceasedCraft profile. The first launch takes a few
   minutes (it installs Forge 1.20.1 and loads all the mods).
2. At the title screen choose **Multiplayer → Add Server**.
3. Server Name: anything. Server Address: `minecraft.rt-541.io:25567`
4. Click **Done**, select the server, **Join Server**.

## Whitelist

The server is whitelisted. If you get *"You are not white-listed on this
server"*, an admin needs to add your Minecraft username in Discord with
`/mc-allowlist add`. (The whitelist is shared with the ATM9 server.)

## Troubleshooting

- **"Can't connect / outdated client or server":** your modpack version doesn't
  match the server. Make sure you're on **5.10.16**.
- **Crashes on launch or heavy lag:** raise allocated memory (step 4).
- **Server seems down:** it may be swapped to ATM9. Anyone with the Minecraft
  role can run **`/swap`** in Discord and pick DeceasedCraft.
